# Security Policy

ALLways is a proprietary project. Security reports should not be disclosed publicly before a fix is available.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If that feature is not enabled, contact the repository owner privately through GitHub.

Please include:
- affected app/repository and version;
- reproduction steps or proof of concept;
- security impact;
- any suggested mitigation.

Do not include secrets, passwords, signing keys, API credentials, or personal data in a public issue.

## Supported versions

Security fixes are prioritized for the latest released version of each ALLways app.
